# weather-pattern-analysis
# 🌦️ Weather Pattern Analysis Using Python

## 📌 Project Overview

This project focuses on analyzing historical weather data to identify patterns and trends in temperature, humidity, precipitation, wind speed, and weather conditions.

The project was developed as part of my **Data Analytics Internship** to demonstrate practical skills in data cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization using Python.

---

## 🎯 Objectives

* Analyze daily weather conditions and patterns.
* Study temperature variations over time.
* Analyze humidity and precipitation trends.
* Examine wind-speed patterns.
* Identify the distribution of different weather conditions.
* Generate meaningful visualizations from the dataset.
* Extract useful insights from historical weather data.

---

## 📊 Dataset

The dataset contains **730 daily weather records**.

### Main Features

| Column            | Description                      |
| ----------------- | -------------------------------- |
| Date              | Date of the weather observation  |
| High Temperature  | Maximum temperature recorded     |
| Low Temperature   | Minimum temperature recorded     |
| Humidity          | Humidity percentage              |
| Precipitation     | Amount of precipitation recorded |
| Wind Speed        | Wind speed recorded              |
| Weather Condition | Observed weather condition       |
| Month             | Month extracted from the date    |

## 🚀 How to Run the Project

### 1. Clone the repository

```bash

```

### 2. Open the project folder

```bash
cd weather-pattern-analysis
```

### 3. Install the required libraries

```bash

```

### 4. Run the Jupyter Notebook

```bash

```


and run the cells sequentially.
